# PTZBrain

Windows-App, mit der sich **OBSBOT Tail 2** PTZ-Kameras bedienen lassen – am Bildschirm, am Tablet und per Sprache.

Hier liegen nur die Installer. Der Quelltext ist nicht öffentlich.

## Herunterladen

Unter **[Releases](../../releases/latest)** die Datei `PTZBrain-Setup-<Version>.exe` laden und starten.

- Windows 10 oder 11, 64 Bit. Keine Administratorrechte nötig.
- Der Installer ist nicht signiert. Windows zeigt deshalb beim ersten Start „Der Computer wurde durch Windows geschützt": **Weitere Informationen → Trotzdem ausführen**.
- Die Spracherkennung wird beim ersten Klick auf „Spracherkennung einrichten" einmalig geladen (rund 250 MB) und läuft danach ohne Internet.

## Was die App kann (Version 0.2.0)

- **Pult:** alle Kameras nebeneinander, je Kamera Steuerknüppel, Zoom, gespeicherte Einstellungen, Verfolgen, Licht, Weißabgleich, Fokus.
- **Koppeln:** mehrere Kameras mit einem Knüppel steuern.
- **Sprache:** kurze Kommandos wie „1 nah", „2 totale", „3 langsamer Zoom out", „alle Mitte", „Zurück". „Stopp" geht immer.
- **Eigene Kurzwörter:** ein Wort stellt mehrere Kameras auf einmal.
- **Kommando-Hilfe** in der App und ein Kommando-Zettel zum Ausdrucken.
- **Tablet:** Bedienung im selben Netz nach einmaliger Kopplung mit Code.
- **Übungskamera** zum Ausprobieren ohne Gerät.

## Hinweise

- Die Kameras müssen im selben Netz wie der Rechner sein. Die Tail 2 verlangt kein Kennwort – für Veranstaltungen empfiehlt sich ein eigenes Netz.
- Eine Kamera hält bei einer Fahrt nicht von selbst an. Die App überwacht das mit einem eigenen Stopp-Wächter; trotzdem gilt: Kamera frei aufstellen.
- Frühe Version, im Aufbau. Nutzung auf eigene Verantwortung.

PTZBrain ist ein Projekt von BeZi-Film und steht in keiner Verbindung zu OBSBOT.
